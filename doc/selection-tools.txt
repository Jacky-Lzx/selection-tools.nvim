1. SETUP                                              *selection-tools-setup*
>lua
    require('selection_tools').setup({
      ui_select = false,
      layout = { width = 0.6, height = 0.5, border = 'rounded' },
      keys = {
        confirm = { '<CR>' },
        close = { '<Esc>', '<C-c>' },
        next = { '<C-n>', '<Down>' },
        previous = { '<C-p>', '<Up>' },
      },
    })
<
Setup is optional. Width/height values <= 1 are fractions of available space;
larger values are columns/rows. Size is clamped to the editor. The picker needs
at least 12 columns and 8 usable rows. Border accepts |nvim_open_win()| styles.

Key lists replace the defaults for that action. Use {} to disable an action.
Bindings are local to picker buffers. The results buffer also maps j/k for
navigation and / to focus the search input in Insert mode.

ui_select=true installs the |vim.ui.select()| adapter. Calling setup with false
restores the previous implementation only if our adapter still owns the slot.
Load the plugin before callers if you want it to handle vim.ui.select calls.
The adapter also supports preview_item and automatically enables its preview.

Layout options: input_position ('top' or 'bottom'), reverse (false), min_width,
max_width, preview_height (0.6) and title_pos ('center'). All panes share one
outer border; there is no backdrop. Reverse places the first match at the bottom
of the list. Movement keys follow screen directions, while move(delta) follows
candidate rank. select.layout overrides the layout for select()/vim.ui.select;
its default is a compact, forward list below an input at the top.

Optional key actions (none are bound by default):
  select_previous / select_next   Toggle mark, then move by rank -1 / +1.
  history_back / history_forward  Browse source history, preserving the draft.
  preview_up / preview_down       Scroll preview by half a window.
  list_up / list_down             Move half a list window in screen direction.
  copy                           Copy marked paths/text to the + register.
  system_open                    Open marked paths/text with the system app.
  ignore                         Consume a key without taking an action.

These actions fall back to the current item if there are no marks. Copy/open
leave the picker open. A custom system_open(path) callback may be supplied;
it should return a success value and an optional error as its second result.
actions = { name = function(picker) ... end } defines custom key actions.

history = { limit = 100, persist = false } stores source-scoped query history.
With persist=true, the default path is stdpath('state') followed by
'/selection-tools/history.json'. Set history.path to override it. Writes are
atomic, and empty queries are not recorded. Forward from the newest entry
restores the query that was being edited before browsing history.

Highlight groups (all use default links and may be overridden):
  SelectionToolsBorder       FloatBorder
  SelectionToolsSelected     Visual
  SelectionToolsMatch        Search

2. USAGE                                              *selection-tools-usage*

:SelectionTools [source]                                    *:SelectionTools*
    Open a registered source. Defaults to files. Supports source completion.

Built-in sources:
  files    Asynchronously enumerate files, then filter the cached list locally.
           Prefer fd; use rg if fd is unavailable. Ignore rules are respected.
           hidden=true includes hidden files. ignored=true disables ignore
           rules. .git is always excluded. cwd defaults to the calling cwd;
           expand ~ or environment variables before passing a path.
  buffers  Listed buffers, current first then most recently used. Pass
           current=false to exclude the current buffer.

Type to search with smart-case fuzzy matching. Lowercase queries ignore case;
queries containing uppercase characters respect case. Enter confirms. Enter
with no matches does nothing. Escape/Ctrl-C cancels. Opening another picker
cancels the old one. Leaving the picker windows cancels it. External window
closure and input buffer destruction also clean up the picker.

The match/total count appears at the right of the input row, with space reserved
for it even when the query scrolls horizontally. Internal dividers join the
outer border and do not display preview filenames. Previews use absolute line
numbers.

File/buffer sources enable preview and multiple selection. Marked files are
added to the buffer list; confirmation displays the first marked file.
The grep source performs live full-text search using ripgrep JSON output.
It defaults to literal smart-case search; regex=true enables regex patterns.
Options include cwd, hidden, ignored, limit (10000) and debounce_ms (30).
Confirming a result opens its exact file/line/column; an empty query does not
start a search.

3. PUBLIC API                                           *selection-tools-api*
>lua
    local selection = require('selection_tools')
<
selection.select(items, opts, on_choice)
    Open a searchable list. Supports arbitrary Lua values. format_item(item)
    returns the displayed/searchable string; defaults to tostring(item).
    on_choice(item, index) receives the original value and original 1-based
    index, even after filtering. Cancellation passes nil, nil. The callback
    runs once, after cleanup and focus restoration. Returns a picker.

selection.open(opts)
    Open a picker with items or finder. Returns a picker. Options:
      items          Candidate list.
      format_item    Display function: fun(item): string.
      prompt         Window title; default 'Select'.
      query          Initial query; default ''.
      on_choice      Optional fun(item, original_index); nils on cancellation.
      finder         Asynchronous/synchronous producer; see below.
      live           Restart finder when query changes; default false.
      match          Locally fuzzy-match results; default true. Set false if
                     a live source already filters/sorts candidates.
      cwd            Source context cwd; default current directory.
      layout, keys   Per-call overrides of setup options.
      multi          Enable marks; default false, true for files/buffers.
      preview        { enabled=false, max_size=1048576, max_lines=10000,
                       max_line_length=1000 }. Built-in sources enable it.
      preview_item   vim.ui.select-style function(item) returning a buffer
                     and optional pos. Caller buffers are displayed directly
                     without changing their options or deleting them.
      previewer      Custom function(ctx), optionally returning a cancel
                     function. ctx contains item, index, buf, win,
                     is_cancelled(), set_lines(lines, ft, title, pos).
                     set_lines is safe from async callbacks. Late results
                     are ignored. The built-in previewer reads files
                     asynchronously and prefers unsaved loaded buffers.

With multi=true, on_choice receives marked items as an additional third
argument; with no marks it contains the current item. The first two arguments
still identify the current item. Cancellation does not return marked items.
Marks survive local filtering but are cleared when the source replaces items.
Binary and oversized files show an explanatory preview message. Preview
scrolling preserves the input focus; preview never edits source buffers.

selection.register_source(name, source)
    Register or replace a source (including a built-in). Name must contain
    only letters, digits, underscores or hyphens. Source is an options table
    or a function(opts) returning an options table.

selection.pick(name, opts)
    Resolve a source, merge per-call opts over its defaults, and open it.
    Unknown sources raise an error. Returns a picker.

selection.files(opts)
selection.buffers(opts)
    Shortcuts for pick('files', opts) and pick('buffers', opts).

selection.sources()
    Return the sorted list of built-in and registered source names.

4. FINDER CONTRACT                                   *selection-tools-finder*

finder(ctx) is called once initially, or again on every query change if live
is true. It should return quickly; use async I/O for expensive work. Optional
return value: a cancellation function. Slow live sources may debounce in their
own finder and cancel their timer in this function.

Context:
  ctx.query              Query snapshot for this invocation.
  ctx.cwd                Calling cwd or explicit cwd.
  ctx.is_cancelled()     True if closed or superseded by another query.
  ctx.set_items(items)   Replace the complete list, retaining original values.
  ctx.done()             Clear loading state.
  ctx.fail(message)      Display and notify an error, clear loading state.

The delivery methods schedule onto Neovim's event loop, so they may be called
from fast callbacks. Call set_items before done. Repeated set_items calls are
allowed. Calls after cancellation are ignored. The cancel function executes
when the picker closes or the finder is superseded, even if done was called;
it should be safe after completion.

Live searches clear previous candidates before starting the new finder. Static
searches continue filtering cached candidates while typing. Local fuzzy matching
uses text only; Lua objects/functions are never passed through Vimscript.

===============================================================================
5. PICKER METHODS                                   *selection-tools-methods*

picker:set_query(query)    Replace input and refresh filtering/search.
picker:set_items(items)    Replace candidates and refresh filtering.
picker:move(delta)         Move selection, wrapping at either end.
picker:move_visual(delta)  Move in screen directions, respecting reverse.
picker:toggle()            Toggle a mark on the current item if multi=true.
picker:selected(opts)      Marked values in source order. opts.fallback=true
                          falls back to the current item if there are no marks.
picker:history_move(delta) Browse previous (-1) or next (+1) query.
picker:scroll_list(dir)    Half-window list movement, -1 up / +1 down.
picker:scroll_preview(dir) Half-window preview scroll, -1 up / +1 down.
picker:current()           Return item, original_index; nils with no selection.
picker:matcher_status()    { backend='none'|'native'|'skim', pending=boolean,
                            error=string|nil }. Last fallback error is retained.
picker:confirm()           Close and choose current item; no-op without matches.
picker:close()             Cancel. Repeated close calls are harmless.

Methods that modify a closed picker are no-ops. Treat all other fields as
internal implementation details.

6. MATCHING BACKENDS                                 *selection-tools-matcher*
>lua
    require('selection_tools').setup({
      matcher = {
        backend = 'auto',
        threshold = 50000,
        skim = {
          command = 'sk',
          algorithm = 'arinae',
          debounce_ms = 10,
          timeout_ms = 10000,
        },
      },
    })
<
auto uses native matching below threshold and skim at/above it, if installed.
The threshold counts all candidates, not current matches. native always uses
matchfuzzypos with cached strings. skim prefers an async sk --filter process.
Skim 5.8.0 is tested; no skim dependency is required to use the plugin.

Each query cancels previous work, including debounce timers, processes and
pending result decoding. Candidate records are cached between queries and
carry original numeric IDs so duplicate labels retain their identities. Only
visible rows need native match positions with the skim backend. The UI stays
native, including preview, marks, clipboard actions and confirmation.

Ranking differs between engines. Queries containing whitespace, ! ^ $ | quotes
or backslashes, NUL, or more than 1024 characters use native matching even in
skim mode. This avoids interpreting literal input as skim's extended search.
Empty queries/lists and match=false bypass the matcher entirely (backend=none).

While async matching is pending, old results are cleared, confirmation is a
no-op, and the list displays Matching…. Existing marks are retained. Missing
executables silently use native matching. A process failure, timeout or invalid
result warns once and falls back to native for the rest of that picker. The
matcher clears SKIM_DEFAULT_OPTIONS for its subprocess. matcher_status reports
the current backend, pending flag and last fallback error.

Per-call matcher options override setup defaults. The threshold is configurable;
it is a conservative default rather than a universal performance crossover.
